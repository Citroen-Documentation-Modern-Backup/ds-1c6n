2. Dépose
Mettre le véhicule sur un pont élévateur , Roues pendantes.
Débrancher la borne négative de la batterie.
Déposer :
  • Le cache-style
  • L’isolant phonique sous le moteur
  • Le pare-boue avant gauche (voir opération correspondante)
Vidanger le circuit de refroidissement (voir opération correspondante).
Déposer :
  • Le boîtier de filtre à air
  • Le connecteur de débit d’air
Lever et caler le véhicule.
Figure : c4ap14sc
Écarter le conduit d’aération ( 3).
Déconnecter le connecteur (1).
Déposer les écrous (2).
Figure : c5hp16qc
Déposer l’écrou (6).
Désaccoupler :
  • Les durits (7) et (8)
  • La durit d’arrivée carburant (5)
Descendre le véhicule près du sol.
Figure : c4ap14tc
Déposer :
  • Les 3 vis (9)
  • Les contreplaques (10)
Lever le véhicule.
Déposer le réchauffeur de circuit d’eau ( 4).
3. Repose
Procéder dans l’ordre inverse des opérations de dépose.
Rebrancher la borne négative de la batterie.
Purger et faire le niveau du circuit de refroidissement (voir opération correspondante).
ATTENTION : Le remplacement du réchauffeur circuit d’eau, nécessite le contrôle de son fonctionnement (voir opération correspondante).
4. Contrôle du fonctionnement
NOTA : Le contrôle s’effectue moteur à froid À l’aide d’un outil de diagnostic.
Brancher l’outil de diagnostic sur la prise centralisée du véhicule.
Effectuer un test global.
Sélectionner le menu : Chauffage additionnel .
Faire un test actionneur : Remplissage carburant.
Actionner pendant 30 secondes la pompe doseuse pour amorcer le circuit de carburant.
Démarrer le moteur pour faire fonctionner la pompe à eau.
Sélectionner le menu : Activation chauffage.
Faire une lecture / effacement défaut.
En cas de mauvais fonctionnement, recommencer le test actionneur.
