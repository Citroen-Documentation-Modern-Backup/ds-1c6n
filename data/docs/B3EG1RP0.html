B3EG1RP0Dépose - repose : Commande sous volant de direction
JUSQU’A OPR 9491
1. Protection
Figure : e1ap080c
Placer une protection sur les éléments suivants :
  • Ailes avant
  • Siège conducteur
  • Tapis de sol (côté conducteur)
  • Volant de direction
2. Dépose
Débrancher la borne négative de la batterie.
IMPERATIF : Respecter les consignes de sécurité.
Déposer le volant de direction (voir opération correspondante).
Figure : c5fp08ec
Déposer :
  • Les 2 vis (1) (TORX 20)
  • L’habillage de la colonne de direction (2)
  • Le raccord tournant de l’allumeur pyrotechnique "airbag" (voir opération correspondante)
Déconnecter les connecteurs de commande sous le volant de direction.
Figure : c5fp08fc
Déposer :
  • Les 3 vis (3)
  • Les commandes sous volant de direction (4)
3. Repose
Reposer :
  • Les commandes sous volant de direction ( 4)
  • Les 3 vis (3)
Connecter les connecteurs de commande sous le volant de direction.
Reposer :
  • Le raccord tournant de l’allumeur pyrotechnique "airbag" (voir opération correspondante)
  • L’habillage de la colonne de direction (/)
  • Les 2 vis (1) (TORX 20)
  • Le volant de direction (voir opération correspondante)
Brancher la borne négative de la batterie.
