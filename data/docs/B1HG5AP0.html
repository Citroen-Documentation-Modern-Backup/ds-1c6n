3. Dépose
IMPERATIF : Procéder à l’opération le moteur froid.
Débrancher la borne négative de la batterie.
Figure : b1bp23bc
Faire chuter la pression dans la rampe d’alimentation des injecteurs en utilisant la pompe [1].
Désaccoupler : Le tuyau d’alimentation carburant (1).
Déposer :
  • Les écrous des goujons du boîtier bobine compacté
  • Les goujons
  • Le boîtier bobine compacté (2)
  • Les 3 vis (TORX) du support de butée de gaine du câble d’accélérateur
  • Le support de butée de gaine du câble d’accélérateur (3)
  • Les 3 vis de fixation de la rampe injection
Déconnecter les connecteurs sur les injecteurs essence.
Déposer la rampe d’alimentation / injecteurs essence ( 4).
Déposer les agrafes.
Déposer les injecteurs essence.

4. Repose
Reposer :
  • Les injecteurs essence ( 5) sur la rampe d’alimentation (4)
  • Les agrafes de maintien (6)

  • La rampe d’injection carburant
  • Le boîtier bobine compacté
Clipper le tuyau d’alimentation carburant.
