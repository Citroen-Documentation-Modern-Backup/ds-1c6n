D4EM02P0Procédure de "télécodage" : Boîtier de servitude intelligent (BSI)
1. Observations
Une lecture des paramètres télécodables, avec l’outil de diagnostic, ne nécessite pas de disposer du code d’accès véhicule inscrit sur la carte confidentielle client.
Le code d’accès Après Vente est indispensable pour effectuer les modifications suivantes :
  • Paramètres de configuration
  • Liste des calculateurs
2. Outillage de diagnostic
Station "LEXIA 4171-T".
Station "PROXIA 4165-T".
3. Procédure de "télécodage"
3.1. Procédure à suivre avec l’outil de diagnostic "LEXIA"
Effectuer les sélections suivantes dans l’outil de diagnostic :
  • "DIAGNOSTIC"
  • "XSARA PICASSO"
  • "TEST GLOBAL"
  • "CALCULATEUR BSI"
  • "TÉLÉCODAGE"
Choisir l’un des sous-menus suivants :
  • "OPTIONS CLIENT"
  • "CONFIGURATION" (voir nota)
  • "CALCULATEURS PRÉSENTS"
NOTA : Le code VIN se trouve dans ce sous-menu.
3.2. Procédure à suivre avec l’outil de diagnostic " PROXIA"
Effectuer les sélections suivantes dans l’outil de diagnostic :
  • "DIAGNOSTIC"
  • "XSARA PICASSO"
  • "BSI"
  • "LOGO F5"
  • "TÉLÉCODAGE"
Choisir l’un des sous-menus suivants :
  • "OPTIONS CLIENT"
  • "CONFIGURATION"
  • "CALCULATEURS PRÉSENTS"
  • "CODE VIN"
3.3. "OPTIONS CLIENT" - Paramètre : "OPTION ALERTE SURVITESSE"
Le seuil d’alerte survitesse est fixe lorsque le paramètre est validé.
Le seuil d’alerte survitesse est variable, au choix du conducteur, lorsque le paramètre n’est pas validé.
3.4. "OPTIONS CLIENT" - Paramètre : "INHIBITION VISUALISATION AUX CLIGNOTANTS"
Ce paramètre doit être validé lors de la pose d’une alarme sur un véhicule direction à droite.
3.5. "CONFIGURATION"
Code VIN du véhicule = 41.
ATTENTION : Les paramètres de climatisation doivent être sélectionnés en fonction de la configuration du véhicule.
Paramètres Configuration du véhicule - Sans climatisation Configuration du véhicule - Climatisation RF (sans régulation de température) Climatisation régulée
"OPTION CLIMATISATION" 0 1 1
"PRÉSENCE CLIMATISATION RÉGULÉE" 0 0 1
"PRÉSENCE CLIMATISATION MULTIPLEXÉE" 0 0 1
3.6. "CALCULATEURS PRÉSENTS"
Ce sous menu comporte la liste des calculateurs équipant le véhicule.
NOTA : Le calculateur de climatisation n’est validé que pour les véhicules équipés d’une climatisation régulée.
