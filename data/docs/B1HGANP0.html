B1HGANP0Dépose - repose : Tubulure de remplissage de réservoir à carburant
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Dépose
Lever et caler le véhicule, roues arrière pendantes.
Déposer :
  • La roue arrière droite
  • Le pare-boue arrière droit
Vidanger le réservoir de carburant.
Figure : b1hg422d
Désaccoupler :
  • Le raccord encliquetable  (en "a")
  • Le conduit réservoir à carburant (2)
Déposer :
  • L’écrou (3)
  • Le fil de masse
Figure : b1hg424d
Déposer :
  • Les vis (4)
  • La tubulure de remplissage de carburant (1)
Figure : b1hg425d
ATTENTION : Contrôler le raccordement du fil de masse (en "b").
2. Repose
Reposer :
  • La tubulure de remplissage de carburant (1)
  • Les vis (4)
  • Le fil de masse  (en "b")
  • L’écrou (3)
Accoupler :
  • Le conduit réservoir à carburant (2)
  • Le raccord encliquetable  (en "a")
Reposer :
  • Le pare-boue arrière droit
  • La roue arrière droite
  • Le véhicule sur ses roues
