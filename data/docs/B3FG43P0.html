B3FG43P0Dépose - repose : Capteur gyromètre Accéléromètre (/)
AVEC SYSTEME ESP DEPUIS OPR 9492
IMPERATIF : Respecter les consignes de sécurité et de propreté (se reporter à la brochure "RECOMMANDATIONS - PRÉCAUTIONS").
1. Dépose
Déposer :
  • Les sièges avant (voir opération correspondante)
  • Le faux plancher (voir opération correspondante)
Figure : c4ap1a5d
Déconnecter le connecteur (en "a").
Déposer :
  • Les écrous (1)
  • Le capteur gyromètre Accéléromètre (2)
2. Repose
IMPERATIF : Respecter le sens de montage du capteur gyromètre-accéléromètre ( 2). Connecteur vers l’arrière du véhicule.
ATTENTION : Tout capteur gyromètre Accéléromètre (2) ayant subi un choc doit être remplacé.
Reposer :
  • Le capteur gyromètre Accéléromètre (2)
  • Les écrous (1)
Serrer les écrous (1) à 0,6 ± 0,1 m.daN.
Reconnecter le connecteur (en "a").
Reposer :
  • Le faux plancher (voir opération correspondante)
  • Les sièges avant (voir opération correspondante)
Effectuer un essai sur route.
Effectuer une lecture des codes défauts.
