D1AG0NP0Dépose - repose : Câble positif de la batterie
1. Protection
Figure : e1ap080c
Placer une protection sur les éléments suivants :
  • Ailes avant
  • Siège conducteur
  • Tapis de sol (côté conducteur)
  • Volant de direction
2. Dépose
Débrancher la batterie (sous le siège avant gauche).
2.1. Dans le compartiment moteur
Figure : b1bp26zc
Déposer l’écrou (1).
Déconnecter le câble positif batterie ( 2a).
ATTENTION : Le câble positif de la batterie ( 2a) arrive à la borne intermédiaire "a". Le câble (2b) n’est que le prolongement du câble positif de la batterie (2a).
2.2. Sous le véhicule
Figure : b3ep123c
Déposer les 2 écrous (3).
Déposer la plaquette de fixation ( 4).
2.3. Dans l’habitacle
Figure : c5gp07cc
Déposer le faux plancher (voir opération correspondante).
Déclipper le câble positif batterie ( 2a).
Désengager le passe gaine ( 5).
Déposer le câble positif batterie ( 2a).
3. Repose
Procéder dans l’ordre inverse des opérations de dépose.
