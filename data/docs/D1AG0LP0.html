D1AG0LP0Dépose - repose : Câble positif de la batterie
1. Protection
Figure : e1ap080c
Placer une protection sur les éléments suivants :
  • Ailes avant
  • Siège conducteur
  • Tapis de sol (côté conducteur)
  • Volant de direction
2. Dépose
Débrancher la batterie (sous le siège avant gauche).
2.1. Dans le compartiment moteur
Figure : b1bp241c
Déposer l’écrou (1).
Déclipper le câble positif batterie.
2.2. Sous le véhicule
Figure : b3ep115c
Déposer les 2 écrous (2).
Déposer la plaquette de fixation ( 3).
2.3. Dans l’habitacle
Figure : c5gp075c
Déposer le faux plancher (voir opération correspondante).
Déclipper le câble positif batterie ( 4).
Désengager le passe gaine ( 5).
Déposer le câble positif batterie ( 4).
3. Repose
Procéder dans l’ordre inverse des opérations de dépose.
