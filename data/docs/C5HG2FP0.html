2. Dépose
Vidanger :
  • Le circuit de refroidissement (voir opération correspondante)
  • Le circuit de réfrigération (voir opération correspondante)
Déposer la planche de bord (voir opération correspondante).
Figure : c5hp14cc
2.1. Côté compartiment moteur
Déposer les 2 écrous (1) (maintenir les goujons (2) à l’aide d’une clé six pans).
Déboîter les tuyaux haute pression et basse pression délicatement (obturer les orifices des tuyaux).
Déposer l’obturateur (3).
Obturer les orifices du détendeur.
Déclipper les agrafes (4).
Déboîter les durits de chauffage ( 5).
Déposer :
  • L’écrou (6)
  • L’obturateur métallique (7)
  • La vis (8) de maintien du bloc chauffage
Figure : c5hp14dc
2.2. Côté habitacle
Déposer :
  • La vis ( 9) de maintien du groupe chauffage
  • Le manchon d’air (10)
  • Déboîter la durit (11) (condenseur évaporateur)
  • Le groupe chauffage
3. Repose
Procéder dans l’ordre inverse de la dépose.
IMPERATIF : Remplacer systématiquement tous les joints d’étanchéité.
